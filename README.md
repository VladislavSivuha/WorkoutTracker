# 🏋️ WorkoutTracker

Веб-приложение для отслеживания тренировочного процесса: создание шаблонов, ведение тренировок, статистика прогресса.

## 📖 О проекте

WorkoutTracker помогает планировать тренировки и фиксировать результаты. Пользователь создаёт шаблоны тренировок, тренируется по ним, записывая вес и повторения, а затем видит статистику: стрик недель, общий тоннаж, топ упражнений и календарь активности.

Приложение построено на ASP.NET Core MVC с брутальным минималистичным интерфейсом (чёрный/белый + оранжевый акцент).

## ✨ Функционал

- 🔐 **Авторизация и регистрация** — вход по логину/паролю, роли (пользователь/админ)
- 🏃 **Каталог упражнений** — справочник с карточками, описанием, изображениями
- 📋 **Шаблоны тренировок** — создание шаблонов с упражнениями, редактирование, удаление
- 💪 **Активная тренировка** — старт по шаблону, добавление подходов (вес × повторения), добавление упражнений «на лету»
- 📊 **Статистика** — стрик недель, общее количество тренировок, топ-5 упражнений по тоннажу, топ-3 пользователей, календарь активности текущего месяца
- ⏱ **Автозавершение** — тренировка завершается через 5 часов, если пользователь забыл

## 🛠 Стек

- **Backend:** ASP.NET Core 8 MVC, C#
- **БД:** PostgreSQL + Entity Framework Core (Npgsql)
- **Frontend:** Razor Views, Bootstrap 5, кастомный CSS
- **Аутентификация:** Cookie Authentication
- **Шрифты:** Zenter SP Demo
